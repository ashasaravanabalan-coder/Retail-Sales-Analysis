Retail Sales Analysis – SQL Assessment

Project Overview
This project analyzes retail sales and returns data for October 2026 using SQL. The objective is to evaluate regional sales performance, product returns, store performance, and data quality issues to support business decision-making.

Database Tables
1.Customers
2.Orders
3.OrderItems
4.Products
5.Stores
6.Returns

Analysis Performed
-Regional gross sales, returns, and net sales comparison.
-Product category return analysis.
-Store-wise sales and return performance.
-Identification of duplicate records and data quality issues.
-Customer and order validation.

Key Findings
-South ranked first in net sales with $13,037.
-North had the highest gross sales but was affected by higher returns.
-Electronics contributed the highest share of North's returns.
-Cedar Market (Store 21) was the top-performing store in South.
-Identified duplicate order items, unmatched customer IDs, and inactive registered customers.

Recommendations
-Improve quality checks for Electronics products at Maple Square.
-Implement duplicate and foreign-key validation.
-Replicate best practices from high-performing stores.
-Encourage inactive registered customers to make their first purchase.
